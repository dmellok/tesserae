Welcome to Tesserae

A few quick steps to get a dashboard onto your first panel. You can skip any time and configure things later under Settings.

  1. Timezone, so schedules fire at your wall-clock time.
  2. Transport, REST API (no broker needed) or MQTT.
  3. Device, pair the panel with a 6-digit code (REST) or register it via discovery (MQTT).
  4. Dashboard, a starter layout, pushed to the panel.

Help shape where Tesserae goes next?

Tesserae is built by one person in their spare time. A tiny, anonymous signal from your install is genuinely the best map I have for what to work on. It takes one click, and it would mean a lot.

Why it helps

Opt in and Tesserae sends an anonymous heartbeat and install count, so I can see how many people run it, on what hardware, and which widgets get used. That decides what gets built, tested, and supported next. Right now I'm mostly guessing, and you'd be turning that guess into real signal.

Completely first-party, and tiny

This only ever talks to api.tesserae.ink, run by me. No third parties, no ad networks, nothing sold. What's sent: your install's random ID, the version, the widgets you add, and a coarse country from your IP (which is then discarded). No accounts, no personal data, no IP addresses stored. Read the exact payload on the privacy page.

Turn it on and you also get

  • Update alerts when a new Tesserae version ships
  • Firmware update indicators for your panels
  • Install counts on widgets, so you can see what the community actually runs
  • A say in the roadmap, counted installs shape what gets built

Either way you're in control. Change it anytime in Settings → System → Online features.
